## RESUMO DO QUE VEREMOS..

  1. [README.md](./aula-1-modulo1/README.md))
      - Teoria.

      - Explicação dos parâmetros do Podman.

  4. [revisao.md](./aula-1-modulo1/revisao.md)

## Como usar

1. Leia o fluxo mental no início da aula.
2. Leia a teoria e os comandos básicos no README da aula.
3. Execute o laboratório principal na ordem apresentada.
4. Execute a extensão de PDB depois do fluxo principal.
5. Pare em cada validação e compare o resultado com a explicação.
6. Termine usando a revisão para explicar o ambiente sem consultar o material.
