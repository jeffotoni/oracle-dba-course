# Contributing

Obrigado por contribuir com este projeto!

## Como contribuir

1. Faça um Fork deste repositório.

2. Clone o seu Fork:

**Fluxo**
*Fork → Clone → Branch → Commit → Push → Create Pull Request.*

## Como fazer um Fork

1. Acesse o repositório:
   https://github.com/jeffotoni/oracle-dba-course

2. No canto superior direito da página, clique no botão **Fork**.

3. Selecione sua conta do GitHub como destino.

4. Aguarde alguns segundos. => O GitHub criará uma cópia do repositório em sua conta.

5. Após o Fork ser criado, clone o seu repositório:

```bash
git clone https://github.com/SEU-USUARIO/oracle-dba-course.git
cd oracle-dba-course
```

6. Crie uma branch para sua contribuição:

```bash
git checkout -b feature/minha-contribuicao
```

7. Faça suas alterações, commit e push:

```bash
git add .
git commit -m "feat: minha contribuicao"
git push origin feature/minha-contribuicao
```

8. Acesse seu repositório no GitHub e clique em **Compare & pull request**.

9. Revise as alterações e clique em **Create pull request**.
